# Original Dino Game 2014

A free, offline dinosaur runner for Android, with a simple browser-based development preview.

## Project goals

- Keep the core game free to play.
- No advertisements during gameplay, paid upgrades, subscriptions, or paywalls.
- Explore optional donations and sponsorships outside gameplay only; these are not implemented.
- Start with Android. Other platforms can be considered later.
- Preserve required open-source notices and avoid Google/Chrome branding or any suggestion of endorsement.

## Development status

**Early setup — not yet a playable app.** The repository and source-provenance notes are in place. The next milestone is to audit the historical Chromium Dino implementation and its complete resource/license set before integrating it and building a browser preview.
