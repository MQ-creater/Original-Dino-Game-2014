# Original Dino Game 2014

A free, monochrome dinosaur runner prototype with original artwork and code.

## Try the prototype

The browser prototype is in `index.html`, `style.css`, and `game.js`.

To publish a playable preview with GitHub Pages:
1. Open the repository's **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. After GitHub Pages finishes publishing, open the URL shown on that page.

## Current features

- Black, white, and neutral grey only.
- Three-line side menu with **Play** and **Donate** options.
- Original geometric dinosaur and obstacle artwork drawn in code.
- Jump with Space, Arrow Up, W, or by tapping the game.
- Score, collision, game-over, and replay.
- No ads, subscriptions, paid upgrades, or paywalls.
- Donate is only an informational placeholder; no payment processing is connected.

## Project goals

The core game stays free to play. Optional donations or sponsorships, if added later, will remain separate from gameplay and will not unlock features.
