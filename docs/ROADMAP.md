# Project roadmap

## Milestone 1 — monochrome browser prototype
- [x] Create the project repository.
- [x] Create an original black-and-white runner prototype.
- [x] Add the three-line side menu with Play and Donate options.
- [x] Add jump controls, obstacles, score, collision, and replay.
- [ ] Enable GitHub Pages and test on the iPad.
- [ ] Fix any issues found during touch-screen testing.

## Milestone 2 — Android app
- [ ] Choose a maintained Android packaging approach compatible with the project.
- [ ] Package the browser build locally so gameplay does not require an internet connection.
- [ ] Add app icon, accessibility details, privacy disclosures, and third-party notices.
- [ ] Test on supported Android screen sizes and devices.

## Milestone 3 — release readiness
- [ ] Review project name and branding before release.
- [ ] Prepare store listing, content rating, privacy/data-safety information, and testing.
- [ ] Have a parent/guardian manage developer-account eligibility, fees, payments, and submission.
- [ ] Keep core gameplay free; any donations or sponsorships must remain optional and outside gameplay.

## Donations
The Donate menu item is an informational placeholder only. No payment processor, account, or donation link is connected. Any future fundraising setup requires adult involvement and a review of applicable platform rules.

The project uses independently written game code and original geometric artwork. It is not intended to reproduce Chromium's original game.
