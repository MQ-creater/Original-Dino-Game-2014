# Project roadmap

## Milestone 1 — source audit
- [x] Create the project repository.
- [x] Record the official Chromium source and license references.
- [ ] Select a fixed historical source revision.
- [ ] Inventory the runner code and all required resources.
- [ ] Verify notices and licenses for each dependency and asset.

## Milestone 2 — browser preview
- [ ] Integrate the audited game source and local assets.
- [ ] Make the game work offline.
- [ ] Check keyboard, touch, screen sizing, pause/resume, and restart.
- [ ] Test on the iPad browser.

## Milestone 3 — Android app
- [ ] Choose a maintained Android packaging approach compatible with the project.
- [ ] Package the browser build locally so gameplay does not require an internet connection.
- [ ] Add app icon, accessibility details, privacy disclosures, and third-party notices.
- [ ] Test on supported Android screen sizes and devices.

## Milestone 4 — release readiness
- [ ] Complete a licensing and trademark review.
- [ ] Prepare store listing, content rating, privacy/data-safety information, and testing.
- [ ] Have a parent/guardian manage developer-account eligibility, fees, payments, and submission.
- [ ] Keep the core gameplay free; any donations or sponsorships must remain optional and outside gameplay.

No store release or fundraising feature is active yet.
